Masuk atau daftarkan akun pada repositori GitHub Anda

Panduan Membuat Token GitHub Fine-Grained
  1. Buka GitHub di browser HP, ketuk foto profil, pilih Settings, lalu Developer settings.
  2. Pilih Personal access tokens, lalu ketuk Fine-grained tokens dan Generate new token.
  3. Pada bagian Repository access, pilih Only select repositories dan pilih repositori NexaBuild Anda.
  4. Buka Repository permissions dan atur izin berikut:
    • Contents: Read and write
    • Actions: Read and write
    • Issues: Read and write
    • Secrets: Read and write, hanya wajib bagi Developer dan Owner
    • Metadata: Read
  5. Ketuk Generate token, salin tokennya, lalu tempel pada kolom Token GitHub di atas.
